# EmberKit

**v0.1.6 采用可读文件名。** backup 本体通过 `mod-index.txt` 保存文件名—SHA-256 对并查重；游戏入口和手动应用保持原有方式。详见[文件名存储说明](docs/readable-filenames.zh-Hans.md)。

简体中文 · **[English](README.md)**

基于 **[ktxiaok / FireAxe](https://github.com/ktxiaok/FireAxe)** 的个人修改版，主要想让刚入坑的求生之路 2 玩家，拿到一份 TXT 清单后更容易开始安装 Mod。

## 感谢原作者

感谢 **ktxiaok** 开发并开源 FireAxe。原项目已有的下载队列、分组、标签、优先级、引用模组和冲突检测，是这个版本的基础。这份修改能够做出来，首先是因为原作者已经完成了这些工作。也感谢每一位 Mod 创作者。

## 我们加了哪些小功能

1. **TXT 清单导入、导出。** 清单保存工坊 ID、标题、启用状态和优先级；接收者打开清单后点击“导入并下载”。下载前检查是否属于求生之路 2、是否提供可用的 VPK。TXT 不包含 Mod 本体，首次安装仍需联网。复制工坊链接后的确认提示会打开同一个“链接下载”页面并填入链接，点击“加入下载队列”后开始下载。
2. **下载结果列表。** 沿用原项目下载队列显示进度和速度；新增可保留的结果记录，展示最终状态、归档路径和失败原因，并支持打开文件位置。每项记录均可移除；删除未安装的失败项时也会清理空条目，游戏运行期间仍可操作，已安装 Mod 的本体会保留。主列表和右侧详情复用已保存的作品标题，数字工坊 ID 单独保留，支持按作品标题搜索。失败且未安装的作品可以重新入队，避免被当成“已有”直接跳过。
3. **分类与对象独立展开。** 首页采用“分类 → 对象 → Mod”的目录，AK、手枪、Hunter 等可同时打开；开关、改标签、重新识别及详情返回保留展开状态。宽屏对象分为双独立列、窄屏单列，Mod 行收紧为标题、有效简介、作者、缩略图和开关，标签在小按钮中编辑。紧凑工具栏与工作区左右独立滚动、可拖动分配宽度。每个 Mod 只归一个分类 / 对象，可手动修改并保存；明确点击列表或详情才切页，完整列表保留空替换位置、全库 / 分组及原冲突判断。
4. **目录自动复用。** 从已保存的设置、模组库路径等信息推断游戏根目录，让设置、导入和本地存储页面共用已知路径。
5. **可读文件名与 TXT 查重。** VPK 实体集中在 `addons/modebackup`，使用“替换对象 - Mod 标题.vpk”；同名但内容不同加序号，中文可保留。`mod-index.txt` 保存文件名—完整 SHA-256 对并用于查找重复候选，实际内容核验后才合并。旧短编号在手动整理 / 应用时迁移，开关、标签、优先级和裁剪参数保留。
6. **手动应用启用状态。** 开关、优先级修改和新 Mod 入库都先显示“待应用”，游戏外也不自动扫描或改写入口；退出游戏、重开管理器和普通检查保留待应用选择。助手启动直接交给 Steam，沿用上次已应用的 Mod，不再启动前整理或应用；连接及勾选的反馈 / 插值设置照常准备。调整完点击“应用 Mod”一次同步，游戏运行时返回主菜单重载；明确整理、检查同步也会同步入口。启用项统一使用指向 `modebackup` 本体的短名 `.vpk` 相对符号链接，不复制 Mod 内容。旧硬链接在同步时转换；创建失败说明原因，不回退硬链接或 Windows `.lnk`。
7. **默认忽略工坊 Hash，保留下载文件。** “链接下载”和“导入 TXT”默认勾选“忽略工坊 Hash 校验”，复制链接后打开的下载页也相同；可取消勾选来开启工坊 SHA-1 比对。Steam 元数据大小不一致只记警告，仍归档有效 VPK；失败时保留已有文件，可在结果页打开。继续验证 VPK 格式并计算存储用的 SHA-256，结果中会注明。
8. **一键应用 Mod（实验）。** 左侧绿色“从助手启动游戏”按钮一次点击启动并建立所需连接。主页面点击“应用 Mod”直接执行，游戏运行时自动断开地图或服务器、返回主菜单、卸载旧附加内容、应用入口，再请求重新挂载并核对游戏的 VPK 加载列表；按钮旁说明退出对局，不再二次确认。未运行时同步本地入口。尚未安装的下载条目会跳过；个别资源仍有旧缓存时需要完整重启。
9. **软件配置随身保存。** 设置、日志、游戏连接配置和崩溃临时文件统一保存在 `EmberKit.exe` 同目录的 `data` 内，不再使用“文档/FireAxe”、AppData 或启动时的工作目录。Mod 库的识别记录、下载历史和备份继续随 `modebackup` 保存。
10. **可选的击杀反馈动画。** 在启动按钮旁启用，选择“所有僵尸”或“仅特感”。本人击杀后骷髅放大落下、缩小并扩散圆环，再滑入最近3个图标的队列，配合爆头图片和音效。沿用普通 Steam 启动，不添加 `-insecure`。参考图片、音效单列来源，不属于项目代码的 Apache-2.0 许可范围。
11. **合集批量下载安装。** 链接下载和 TXT 导入支持作品或合集，递归展开子合集并去重，已有作品跳过，显式单项设置优先；不更改 Steam 账号订阅。
12. **可选手枪连点。** 工具区底部“附加功能”中的独立开关默认关闭，沿用已保存设置；启用并通过助手重新启动后，手枪按住左键连续点击，松开、菜单、切出或换武器时停止，不修改射速。
13. **可选联机插值预设。** 启动设置中勾选“联机插值预设（65 ms）”，通过助手启动时自动设置 `cl_interp_ratio 1; cl_interp 0.065`。默认关闭、自动保存，主页面与工坊入口共用；单独启用不加载原生模块，实际值可能受服务器限制。
14. **问题定位与地图提示。** 点击浮动问题窗口中的作品名，目录会展开、滚动并高亮对应 Mod，窗口保持打开，便于直接调整开关。战役标记可识别资源分包；地图间普通共用资源改为兼容性提示，同名地图 / mission 内容不同及非地图冲突仍提醒，完整文件明细保留。
15. **本地 VPK 导入。** 左侧“导入 VPK”或文件菜单可多选本地文件，保留外部源文件，校验归档、去重并定位分类，显示导入 / 已有 / 失败数量。游戏中也可入库，等明确点击“应用 Mod”再重载；已有相同内容保留原开关和标签。
16. **按需动画裁尾。** 勾选分类内 Mod 左侧的“选择”，打开“附加功能”核对名称并明确读取，才显示动画时长；换弹和切枪各有独立的负小数秒输入，预览整帧裁量和受影响事件，支持批量逐项处理。可勾选“处理后停用旧版并启用新版”，始终保留旧文件与记录；删除改为分类行的独立按钮，应用仍需明确点击。目前支持已验证的 MDL49/53 内置非循环动画，不支持的格式逐项说明；修改客户端动画不保证缩短服务器开火等待。
17. **分享裁剪参数。** 派生 VPK 和 TXT v2 记录最初工坊来源、原版 SHA-256、完整有序换弹 / 切枪裁剪步骤。多次处理仍可重建，同 ID 的原版和多个派生版分别保留；别人导入时只下载一次原版，再生成派生版并恢复各自开关和优先级。原版版本不符会保留下载并说明原因；仅本地来源无法靠工坊 TXT 还原。目录只为处理过的 Mod 显示简短裁剪记录。

下载只在明确点击下载、导入等入口时触发。临时文件放在 `firefox_temp`，校验后归档；启动、检查和重新识别不会自动重新下载工坊作品。游戏入口的核验与画面实际效果分开确认，最终仍需进入地图测试。

## 快速使用

完整解压软件，运行 `EmberKit.exe`，打开游戏的 `left4dead2/addons`，确认自动填入的游戏根目录，再导入收到的 TXT 清单。下载结束后查看“下载结果”，核对已安装数量和启用状态，然后启动游戏。

更详细的步骤、存储路径与常见问题见 **[使用说明](docs/usage.zh-Hans.md)**。

## 从源码构建

安装 .NET 10 SDK，以及用于反馈模块的 Visual Studio 2022 C++ Build Tools（v143、Win32 和 Windows SDK）。助手以 Windows x64 为目标，游戏模块与加载器使用 x86。

```powershell
dotnet restore FireAxe.Checks/FireAxe.Checks.csproj
dotnet run --project FireAxe.Checks/FireAxe.Checks.csproj -c Release
powershell -ExecutionPolicy Bypass -File scripts/package-windows.ps1
```

普通自检命令只创建临时 VPK、模拟游戏目录、模拟控制台和无桌面的界面预览，不操作真实游戏目录。当前共有 **390 项检查**；`scripts/build-feedback.ps1 -RunChecks` 另覆盖原生动画、输入状态、纹理生命周期、归属和隔离进程装载。动画导出采用游戏支持的 VPK 1 布局，发布前验证所有文件 CRC；游戏内效果仍需另外实测。

打包脚本输出 `publish/EmberKit-Windows-x64-Portable` 文件夹和同名 ZIP，自带运行库，完整解压后运行其中的 `EmberKit.exe`。默认只打包空白 `data`；可用 `-WorkshopListPath` 附带 TXT 清单，用 `-OutputDirectory` 指定新的输出目录。为避免夹带个人配置，脚本不会复用已存在的输出目录或 ZIP。内部程序集与命名空间保留 FireAxe 名称以兼容原项目。
