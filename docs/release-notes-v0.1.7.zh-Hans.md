# EmberKit v0.1.7 · Windows 便携版

启动游戏前不再执行完整的 Mod 整理与应用，减少交给 Steam 之前的等待。

## 更新内容

- “从助手启动游戏”和工坊页启动按钮直接通过 Steam 启动，沿用上次已应用的 Mod 入口。
- 待应用的开关、优先级和新 Mod 保持待应用，不再因启动游戏而自动提交。需要生效时手动点击“应用 Mod”；进入主菜单后也可以应用。
- 移除启动前全库整理及其警告门槛；启动区和工坊页明确提示 Mod 改动需要手动应用。
- 控制台认证连接、击杀反馈、手枪连点和联机插值预设仍按原勾选准备，不添加 `-insecure`。
- 手动“应用 Mod”仍负责文件校验、启用入口和清单同步；游戏运行时会返回主菜单并重新挂载。该流程沿用现有实现。
- 保留 v0.1.6 的可读 Mod 本体名、TXT 文件名—Hash 对照和已验证的查重方式。

## 下载与升级

完整解压 `EmberKit-v0.1.7-Windows-x64-Portable.zip`，运行 `EmberKit.exe`。自带 .NET 运行库。

升级前关闭旧程序，保留自己的 `data`；Mod 库仍在游戏的 `addons/modebackup`。启动只读取已有加载入口，需要应用新选择时请手动操作。

发行包使用全新构建目录和空白 `data`，不包含个人配置、连接密码、日志或实际 Mod。`L4D2-Mod-Share.txt` 沿用此前已公开的 45 项分享清单。

390 项检查通过。新增检查在进程启动边界截获请求，确认有待应用改动和未整理文件时仍可交给 Steam，库文件、链接、清单和待应用选择保持不变，认证连接及插值参数仍正确；检查不启动真实 Steam 或游戏。
