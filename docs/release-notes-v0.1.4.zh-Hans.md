# EmberKit v0.1.4 · Windows 便携版

分类成为主工作区：每个 Mod 只归一个分类，点击原地展开，直接查看简介和调整开关。

## 更新内容

- 分类首页以大卡片显示枪械、感染者、生还者、近战、补给等对象；左侧工具栏缩紧，左右独立滚动，分隔条可拖动分配宽度。
- 每个 Mod 只有一个分类和对象标签，附带的图标、声音、脚本不再导致重复归类。完整资源匹配继续用于冲突检查。
- 点击分类在当前行下方展开 Mod，具体对象标签在原处筛选；显示简介、已有缩略图和启用开关。只有点击“完整列表”或“详情”等明确入口才切换页面。
- 支持手动更改唯一分类标签或恢复自动识别；标签随 Mod 库保存，重新识别后保留。
- 主页面“应用 Mod”改为一次点击执行。游戏运行时自动退出当前对局、返回主菜单并重载；按钮旁标注此行为，不再二次确认。未运行时同步本地入口。
- 工坊下载支持合集及子合集，展开并去重后批量下载安装；已有作品跳过，显式单项设置优先。不修改 Steam 账号订阅。
- Steam 元数据大小不一致时，仍保留并归档有效 VPK，只记录警告。下载失败后保留已有文件，结果页可打开其位置；工坊 Hash 仍默认忽略，VPK 格式和本地 SHA-256 身份检查保留。
- 新增独立的手枪自动连点开关，默认关闭；启用后通过助手重新启动游戏，使用手枪时按住左键连续点击。松开、打开菜单、切出游戏或换用其他武器时停止；不修改武器射速，不需要 `-insecure`。

## 下载与升级

完整解压 `EmberKit-v0.1.4-Windows-x64-Portable.zip`，运行其中的 `EmberKit.exe`。自带 .NET 运行库，无需另装 SDK。

发行包从全新输出目录生成，`data` 为空，不包含个人设置、连接密码、日志或实际 Mod 文件。升级时保留自己的 `data`；Mod 本体和库记录仍保存在游戏的 `addons/modebackup`。附带的 `L4D2-Mod-Share.txt` 沿用上一版已公开的分享清单。

主菜单重载仍为实验功能，部分缓存可能需要完整重启。击杀反馈沿用 v0.1.3 的动画和普通 Steam 启动方式。手枪连点已通过模拟状态与输入检查，尚待单独的真实游戏实测。
