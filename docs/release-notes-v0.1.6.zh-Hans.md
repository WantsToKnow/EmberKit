# EmberKit v0.1.6 · Windows 便携版

正式采用已验证的可读文件名，让 `modebackup` 中的真实 Mod 文件更容易辨认。

## 更新内容

- 本体优先按“替换对象 - Mod 标题.vpk”保存，保留中文；Windows 不支持的字符会清理，过长名称适当缩短。
- 同名但内容不同的文件加序号，例如 `AK-47 - 同名枪皮 (2).vpk`，不会因名称相同而覆盖另一款 Mod。
- `mod-index.txt` 在入库时即保存文件名—完整 SHA-256 对，用于查找重复候选；核验实际内容后才复用。表中 Hash 不符时保留原件并报告原因。
- 旧短编号和完整 Hash 名本体在明确应用 / 整理时迁移，保留内容、Mod 身份、开关、标签、优先级和裁剪参数。打开软件和普通检查不会自动改名。
- 游戏顶层入口继续使用短 Hash 名相对符号链接，保持游戏路径长度限制和原有加载方式。修改仍先显示待应用，退出游戏不自动提交。
- 移除文件名试验版标记，文件名方案成为正式版默认行为；其他功能沿用 v0.1.5。

## 下载与升级

完整解压 `EmberKit-v0.1.6-Windows-x64-Portable.zip`，运行 `EmberKit.exe`。自带 .NET 运行库。

升级前关闭旧程序，保留自己的 `data`；Mod 库仍在游戏的 `addons/modebackup`。首次迁移旧名称，请退出游戏后点击“应用 Mod”或本地存储中的整理按钮。不要同时用多个管理器操作同一个库。

发行包使用全新构建目录和空白 `data`，不包含个人配置、连接密码、日志或实际 Mod。`L4D2-Mod-Share.txt` 沿用此前已公开的 45 项分享清单。
