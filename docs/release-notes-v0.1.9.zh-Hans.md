# EmberKit v0.1.9 · Windows 便携版

## 更新内容

- 在模组目录中勾选作品后，点击右上角的「删除所选 (N)」即可批量删除。可以跨分类勾选，按钮显示实际选中的 Mod 数量。
- 确认窗口会列出作品名称。裁剪过动画的版本还会显示裁剪摘要，方便区分同一作品的不同版本。确认后删除所选 Mod 的库记录和对应的 VPK 文件，取消则保留这些记录和文件。

## 下载与升级

完整解压 `EmberKit-v0.1.9-Windows-x64-Portable.zip` 后运行 `EmberKit.exe`。便携包自带 .NET 运行库。升级前关闭旧程序并保留自己的 `data`。Mod 库位于游戏的 `addons/modebackup`。

包内附带此前公开的 45 项 `L4D2-Mod-Share.txt` 清单。基于 ktxiaok/FireAxe 0.7.3，原作者与贡献者信息见 `NOTICE.txt`，许可证见 `LICENSE.txt`。
