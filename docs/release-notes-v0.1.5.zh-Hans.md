# EmberKit v0.1.5 · Windows 便携版

日常修改保留为待应用，调整完成后再统一应用；新增本地 VPK 导入、动画裁尾和可复现的 TXT 分享参数。

## 更新内容

- 游戏内外的开关、优先级修改都先显示“待应用”，退出游戏和重开管理器不再自动提交。普通检查只核对已有入口，避免每次切换都执行完整扫描；应用、检查同步、明确整理和助手启动仍按手动操作同步。
- 分类与具体对象可独立展开，宽屏双列、窄屏单列；保留其他目录的展开位置。左侧工具保持紧凑，Mod 行直接显示可用缩略图、简介和开关。
- 分类行新增选择、删除与文件位置入口。选择用于附加功能，可直接多选；文件位置会选中实际 VPK 本体。修复详情删除父组与子项等多选场景的崩溃。
- 本地 VPK 支持批量导入，保留外部原文件，按内容去重。下载、导入和裁剪替换先入库待应用，游戏中也可导入。
- 附加功能增加换弹、切枪两种独立尾部裁剪，支持批量逐项输入负小数秒，读取后才显示时长。按模型帧率预览实际裁量及受影响事件；输出兼容求生之路 2 的 VPK 1。
- 可选择停用旧版并启用裁剪版，始终保留旧文件。TXT v2 记录原版来源、SHA-256 和完整有序裁剪步骤；导入时下载一次原版后生成派生版，保留原版及每个版本的开关、优先级。来源版本不同会说明原因并保留原版。
- 问题列表以浮窗保留，点击作品名可展开并定位对应分类；地图间共用资源作为兼容性提示，同名地图或非地图冲突继续提醒。
- 启动设置新增默认关闭的联机插值预设，通过助手启动时添加 `cl_interp_ratio 1; cl_interp 0.065`。手枪连点移入附加功能，原设置保留。

## 下载与升级

完整解压 `EmberKit-v0.1.5-Windows-x64-Portable.zip`，运行 `EmberKit.exe`。自带 .NET 运行库，无需另装 SDK。

发行包使用全新构建目录和空白 `data`，不包含个人设置、连接密码、日志或实际 Mod。本体继续保存在游戏的 `addons/modebackup`，稳定版仍采用短编号命名。升级保留自己的 `data` 和游戏内 Mod 库即可。随包提供的 `L4D2-Mod-Share.txt` 沿用 v0.1.4 已公开的 45 项清单。

客户端动画调整不会修改服务器的开火计时；仅有本地来源的实验包无法只靠工坊 TXT 还原，分享时需另提供本体。主菜单重载仍为实验功能，缓存未更新时可能需要完整重启游戏。
