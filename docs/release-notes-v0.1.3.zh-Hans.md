# EmberKit v0.1.3 · Windows 便携版

本版新增可选的击杀反馈动画，并包含下载默认设置的改进。

## 更新内容

- 启动区增加击杀反馈开关，可选择所有僵尸或仅特感（含 Tank / Witch）。
- 本人击杀后，骷髅放大落下、缩小并触发扩散圆环，再滑入队列左侧；旧图标平滑右移、淡出，保留最近3个。
- 图标最终大小为初版的一半，保留爆头图标、击杀类别与音效，取消连杀数字和倍率。
- 沿用普通 Steam 启动，不添加 `-insecure`；反馈默认关闭，勾选后通过助手重新启动游戏生效。
- 增加模块初始化回执、事件/归属/绘制计数和异常现场日志，放在软件旁的 `data/Feedback`。
- 新下载默认自动启用，默认跳过工坊 SHA-1 比对；大小、VPK 格式检查与本地 SHA-256 身份计算继续保留。

## 下载与升级

完整解压 `EmberKit-v0.1.3-Windows-x64-Portable.zip`，运行其中的 `EmberKit.exe`。自带 .NET 运行库，无需另装 SDK。

发布包使用全新输出目录和空白 `data`，不包含个人配置、连接密码、日志或实际 Mod 文件。升级时保留自己的 `data`；游戏 Mod 本体与库记录继续保存在游戏目录的 `modebackup`。附带的 `L4D2-Mod-Share.txt` 沿用上一版本已公开的分享清单。

击杀反馈针对已适配的 L4D2 客户端构建；游戏文件不匹配时会提示。普通启动不等于所有服务器或 VAC 兼容性承诺。
