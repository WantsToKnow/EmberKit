# 可读文件名与 Hash 对照

从 v0.1.6 起，`addons/modebackup` 中实际 VPK 使用贴近 Mod 功能的名称。

## 实际文件名

例如：

```text
modebackup/
  AK-47 - MW2019 AK-47.vpk
  Hunter - 示例模型.vpk
  AK-47 - 同名枪皮.vpk
  AK-47 - 同名枪皮 (2).vpk
  mod-index.txt
```

优先使用包内标题、可用工坊标题及实际替换对象；中文可保留，Windows 不支持的字符会清理，过长名称会缩短。同名而内容不同的包追加序号，相同内容只保留一份。裁剪版标题为通用标记时，会带上可用的裁剪摘要帮助区分。

`mod-index.txt` 在入库时即记录文件名与完整 SHA-256，软件按这些记录查找重复候选，再验证实际文件内容。缺少库节点或 JSON 整理记录时，仍可使用 TXT 找回已有本体；表中 Hash 错误时不会因此覆盖或删除实际原文件。手动应用后对照表还会补充标题、工坊来源、作用和入口状态。

## 使用

运行本目录 `EmberKit.exe`。升级时关闭原程序并保留自己的 `data`，或复制原程序的 `data/Settings.json` 到新程序的 `data` 以沿用设置；也可以直接打开自己的游戏 Mod 目录。

已有短编号不会因打开程序或普通检查而改名。退出游戏后，明确点击“应用 Mod”或本地存储中的整理按钮，才会迁移旧本体名称，并更新库记录和相对链接。游戏运行中仍允许导入，已挂载本体保持原样。

游戏顶层入口继续使用短 Hash 名，指向可读名称的实体；启用选择、唯一标签、优先级、裁剪参数、手动应用等沿用稳定版。不要同时让两版程序操作同一个库。

如需回退到 v0.1.5 的短编号方式，退出游戏后使用 v0.1.5 的本地整理功能重新核对库；本体内容和原有选择会被保留。旧版安装包见 <https://github.com/WantsToKnow/EmberKit/releases/tag/v0.1.5>。
